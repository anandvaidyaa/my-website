03 Architecture lab

How the pieces fit together.

An illustrative reference architecture for the kind of serverless integration I build. It is based on patterns from my work, not a diagram of a specific production system. Pick a flow or select any service.

Illustrative

Overview

Event-driven integration on Azure

Requests enter through API Management, which authenticates and throttles them. Azure Functions run the business logic and hand long-running workflows to Logic Apps. State lands in Cosmos DB or SQL. Services authenticate with Managed Identity, and everything is provisioned from Bicep through Azure DevOps.

  • Scales with demand, down to zero when idle
  • No secrets stored in configuration
  • Every environment rebuilt from the same code

Entry point

Clients & partner systems

Web and mobile apps, marketplaces and carrier systems that send orders, events and webhooks.

In my work: Shopify, Amazon and Walmart order channels; FedEx, DHL and UPS carrier integrations.

Gateway

Azure API Management

A single front door for every API: OAuth 2.0 / JWT validation, rate limiting, caching and versioning, so backends stay simple and protected.

In my work: FSP Consulting’s serverless architecture and the carrier & shipping integration layer.

Compute

Azure Functions

Event-driven business logic: validate, transform and route each message. Scales out under bursts and to zero when idle.

In my work: order processing, inventory sync and webhook handlers.

Orchestration

Logic Apps

Long-running and multi-step workflows with built-in connectors, retries and approvals, kept out of the request path.

In my work: approval flows, cross-system data sync and carrier dispatch.

State

Cosmos DB & SQL Server

Cosmos DB for high-throughput, low-latency order and inventory state; SQL Server for relational, transactional records.

In my work: real-time e-commerce inventory, ledgers and order history.

Security

Managed Identity

Each service gets its own Entra ID identity and least-privilege RBAC role, so nothing needs a stored password or connection string.

In my work: replaced exposed credentials in legacy systems at FSP Consulting.

Infrastructure as code

Azure Bicep

Every resource on this diagram is declared in Bicep, reviewed in pull requests and deployed identically to each environment.

In my work: the zero-downtime deployment pipeline that cut release time from 2 days to 15 minutes.

Delivery

Azure DevOps pipelines

Multi-stage YAML pipelines: build, test, security scan, provision with Bicep, then promote through environments with approval gates.

In my work: blue-green, zero-downtime releases to Azure.

01 Client project · Event-driven integration

Multi-Channel Order Processing Platform

Problem
Sellers were losing orders and overselling stock because inventory syncs between Shopify, Amazon and Walmart lagged badly.
Architecture
An event-driven integration backend: Azure Functions ingest, normalise and distribute inventory updates in real time, with Cosmos DB holding order and inventory state.
Key decisions
Serverless, event-driven compute that scales with order bursts instead of fixed servers; one normalised inventory model shared by every channel.
  • Azure Functions
  • Cosmos DB
  • ASP.NET Core

02 Client project · Infrastructure as code & CI/CD

Zero-Downtime Cloud Deployment Pipeline

Problem
Manual deployment steps caused environment drift, delayed releases by days and led to frequent production rollbacks.
Architecture
A fully automated infrastructure-as-code pipeline: Azure Bicep templates deployed through Azure DevOps to provision consistent, immutable environments.
Key decisions
Infrastructure versioned alongside the application so every environment is built from the same source; redeploy rather than patch servers by hand.
  • Azure Bicep
  • Azure DevOps
  • YAML pipelines

03 Client project · API gateway & security

Carrier & Shipping Integration Layer

Problem
Dispatch teams spent hours creating shipping labels and tracking packages by hand across separate FedEx, DHL and UPS portals.
Architecture
A centralised, secure API gateway on Azure API Management with OAuth 2.0, automating carrier integrations, label generation and live webhook tracking.
Key decisions
One gateway in front of every carrier, so authentication, throttling and versioning live in one place; webhooks for live tracking updates.
